# Terms of Use — Paris Explorer channel automation

_Last updated: 11 August 2026_

These terms govern the use of the Paris Explorer automation tool, the
internal software in this repository used by the **Paris Explorer** YouTube
channel to produce and publish its own videos.

## 1. Scope and users

The tool is an internal command-line application with a single authorized
user: the owner of the Paris Explorer YouTube channel. It is not offered as
a service, has no accounts, and grants no access to third parties. Cloning
this public repository does not grant any right to use our API credentials,
channel, or brand.

## 2. YouTube API Services

The tool uses **YouTube API Services**. By using it, its user agrees to be
bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms).
Google's handling of data is described in the
[Google Privacy Policy](http://www.google.com/policies/privacy).

## 3. Privacy

The handling of API data is described in our
[Privacy Policy](PRIVACY.md). In short: the tool accesses only the
channel's own data, stores nothing about any other person, and shares
nothing with third parties.

## 4. Acceptable use

The tool may only be used to publish original or properly licensed content
to the Paris Explorer channel, with truthful metadata, in compliance with
the YouTube Terms of Service and Community Guidelines. It must not be used
for spam, misleading metadata, artificial engagement, or bulk account
operations of any kind.

## 5. Revocation and termination

API access can be terminated at any time by revoking the OAuth grant at
<https://myaccount.google.com/permissions>. Stored tokens then become inert
and are deleted.
